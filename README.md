# All-things-public
Public facing scripts to show for a portfolio 

## Projects

| Folder | What it is |
|---|---|
| [`Iru/`](Iru/) | macOS scripts and configuration profiles for Kandji / Iru device management: security audits, software audits and remediation, OS update reminders, onboarding, and the IruPulse telemetry agent |
| [`GoogleExtensionManager/`](GoogleExtensionManager/) | Google Apps Script that inventories Chrome extensions across a Google Workspace domain, scores them for risk, and gives admins a review web app with Slack alerts |
| [`JSM-Assets-Pipeline/`](JSM-Assets-Pipeline/) | Cloud Run Job that syncs devices and assets from CrowdStrike, Intune, Kandji / Iru, Apple Business Manager, NinjaOne and Workday into Jira Service Management Assets through Assets Data Manager |
